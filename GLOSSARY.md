The first batch follows the source's casing, uses infinitives for actions and nouns for categories. Pronouns, skill names, stress messages and seasonal/world-specific terms remain unchanged until contextual review. Font coverage for all six Esperanto diacritics is a separate in-game check, not evidence of terminology approval.

The second batch adds 28 inventory and popup strings. Prompts addressing the player use imperatives (`Elektu`, `Serĉu`); action labels remain infinitives. The inventory stacking note uses `samaj objektoj grupigitaj` to describe duplicate items grouped together. Placeholder counts and order remain unchanged; confirm the count labels and pet filter in-game.
